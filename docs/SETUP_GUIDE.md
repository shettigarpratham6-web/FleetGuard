# FleetGuard Setup & Installation Guide 🚀

Follow this comprehensive step-by-step guide to get FleetGuard running locally or deployed to production.

---

## 🛠️ System Prerequisites

Ensure you have the following installed on your developer machine:
- **Node.js** (v18.0.0 or higher) → `node -v`
- **npm** (v9.0.0 or higher) → `npm -v`
- **PostgreSQL** (v14 or higher) OR a **Supabase** account.
- **Git** → `git --version`

---

## 📥 1. Clone & Install Dependencies

```bash
# Clone the FleetGuard repository
git clone https://github.com/shettigarpratham6-web/FleetGuard.git
cd FleetGuard

# Install Backend Node.js packages
cd backend
npm install

# Install Frontend Next.js packages
cd ../frontend
npm install
```

---

## 🔑 2. Environment Configuration

### Backend Environment Configuration (`backend/.env`)
Create a file named `.env` in the `backend/` directory:

```env
# Server Config
PORT=5000
NODE_ENV=development

# JWT Authentication
JWT_SECRET=super_secret_fleetguard_key_2026
JWT_EXPIRES_IN=7d

# Option A: Full Connection String (Recommended for Supabase/Cloud PostgreSQL)
DATABASE_URL=postgresql://postgres.xxx:password@aws-0-us-east-1.pooler.supabase.com:5432/postgres

# Option B: Individual Connection Parameters (Local PostgreSQL)
# DB_HOST=localhost
# DB_PORT=5432
# DB_USER=postgres
# DB_PASSWORD=your_password
# DB_DATABASE=fleetguard
# DB_SSL=false
```

### Frontend Environment Configuration (`frontend/.env.local`)
Create a file named `.env.local` in the `frontend/` directory:

```env
NEXT_PUBLIC_API_BASE_URL=http://localhost:5000/api
```

---

## 🗄️ 3. Database Setup & Initialization

FleetGuard features **Auto Schema Initialization**. On server startup, `src/config/initDb.js` executes DDL queries to create all missing tables, foreign key constraints, indexes, triggers, and extensions.

### Manual Seed Execution
To populate the database with default branches, vehicles, driver accounts, and test compliance data:

```bash
cd backend
npm run seed
```

#### Default Credentials Generated by Seed:
- 👑 **System Admin:** `admin@fleetguard.com` / `admin123`
- 💼 **Fleet Manager:** `manager@fleetguard.com` / `manager123`

---

## 💻 4. Running the Development Applications

Open two terminal sessions:

### Terminal 1: Start Backend Express API Server
```bash
cd backend
npm run dev
```
*Backend will start on `http://localhost:5000` with hot-reloading via Nodemon.*

### Terminal 2: Start Frontend Next.js Web App
```bash
cd frontend
npm run dev
```
*Frontend will start on `http://localhost:3000` powered by Turbopack.*

## ❓ Troubleshooting & FAQs

### Q: `initDb.js` fails with SSL error when connecting to Supabase?
Ensure your `DATABASE_URL` contains `sslmode=require` or set `DB_SSL=true` in `backend/.env`. FleetGuard automatically enables SSL if `supabase` is detected in the connection string.

### Q: Multer file uploads fail with `ENOENT` error?
Check that the upload folders exist in `backend/uploads/`:
- `backend/uploads/insurance/`
- `backend/uploads/inspection/`
- `backend/uploads/emissions/`
- `backend/uploads/service/`
The server creates these automatically, but ensure user write permissions are granted.

### Q: Port 5000 is already in use?
Change `PORT=5001` in `backend/.env` and update `NEXT_PUBLIC_API_BASE_URL=http://localhost:5001/api` in `frontend/.env.local`.
